# Методы API Яндекс Метрики

Файл собран из `spec/metrika-api.json` скриптом `tools/build-skill-reference.mjs`. Руками не правится: спека обновляется из документации Яндекса ежедневно, и правка потерялась бы при первой же пересборке.

Всего методов: **108**. Вызов: `npx -y yandex-metrika-mcp-server call <имя> --параметр значение`. Полный список параметров одного метода: `... describe <имя>`.

Помеченные «меняет данные» требуют `METRIKA_ALLOW_WRITES=1`. Без неё они отказывают, не обращаясь к API: удалённую цель или счётчик восстановить нечем.
